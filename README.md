# Three.js Midterm Project-Christian Toliver

## Medieval Fantasy Courtyard

This project is a nighttime medieval fantasy courtyard created with Three.js. 
The scene includes a castle, towers, courtyard walls, banners, a fountain, 
crates, a barrel, a dead tree, and an animated gate.

## Controls

- 1 - Toggle fountain glow
- 2 - Toggle banner and fountain animation
- 3 - Toggle gate spotlight
- 4 - Toggle gate opening and closing

## Features

- Multiple geometry types
- Object translation, rotation, and scaling
- MeshStandardMaterial
- MeshPhysicalMaterial
- MeshPhongMaterial
- MeshLambertMaterial
- MeshToonMaterial
- Ambient light
- Point light
- Spot light
- Dynamic shadows
- Animated fountain
- Animated banners
- Animated castle gate
- OrbitControls
